# 🛒 BIG_BUY - Online Shooping Management System SQL Database Project

## 📌 Project Overview

BIG_BUY is an SQL-based e-commerce database system that simulates the backend of an online shopping platform. It includes core modules like Users, Products, Orders, Payments, Reviews, and Shipping. The schema is normalized and relational, ideal for learning advanced SQL concepts like constraints, foreign keys, joins, and more.

---

## 🛠️ Technologies Used

- **MySQL**: Database management system
- **SQL**: DDL and DML (for table creation and data manipulation)
- **Workbench / CLI**: For executing and managing queries

---

## 📂 Code Explanation

This project includes:

- **User Management**: Stores user details and handles relationships with orders and payments.
- **Product Catalog**: Maintains product inventory and connects to suppliers.
- **Order System**: Handles customer orders and integrates with shipping and payments.
- **Reviews**: Customers can rate and review products.
- **Shipping & Payments**: Tracks delivery and transaction status.
